# Triage labels

When a skill names a triage role, use the corresponding GitHub label.

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the request. |
| `needs-info` | `needs-info` | The maintainer needs more information from the reporter. |
| `ready-for-agent` | `ready-for-agent` | The request is specified and ready for an agent to implement independently. |
| `ready-for-human` | `ready-for-human` | The request requires human implementation. |
| `wontfix` | `wontfix` | The request is declined. |
