# DogeDock

DogeDock is a dock for Omarchy Shell that displays application icons and gives users access to extensions through Dock icons.

## Language

**Dock extension**:
A DogeDock add-on that can supply zero or more Dock icons, each with its own state and interactions.
_Avoid_: Omarchy Shell plugin

**Extension icon**:
An individual Dock entry supplied by an extension, with its own appearance and interactions.

**Extension setting**:
A named field defined by an extension for the user to configure. A field accepts one value or a list of values of the same type.

**Extension setting value**:
The user's selection or input for an extension setting.

**Built-in extension**:
A Dock extension distributed with DogeDock and identified by its extension ID.

**External extension**:
A Dock extension distributed independently of DogeDock and identified in the user's settings by its directory.
