# Wallpaper

Enable **Wallpaper** under **Settings → Extensions**, then click its **Settings** button or select **Wallpaper** in the sidebar. Choose **Single image** or **Directory rotation**, select an image or directory, and click **Apply**.

## Directory rotation

By default, Wallpaper starts with the first supported image and rotates in filename order every 15 minutes. Choose **Random** to pick a different image at each switch when another one is available. Both orders scan the top level of the directory at each interval.

Rotation continues when you close Settings and resumes its timer after Omarchy Shell restarts. Omarchy's theme and manual background changes take effect immediately. Disable Wallpaper to stop rotation and keep the current background.

## Dock icon

Turn on **Show icon in Dock** in Wallpaper settings. Either mouse button opens the same menu. In single-image mode, the menu lets you choose a new image. In directory mode, you can change or open the rotation directory and choose the rotation order. Both modes let you save a copy of the current wallpaper.

You can also drop local images onto the icon. Single-image mode applies the first supported image. Directory rotation copies supported images into the selected directory and keeps existing files.
