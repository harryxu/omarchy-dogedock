# Folders

Folders starts with your `~/Downloads/` directory. To pin another folder, open **Settings → Extensions**, enable **Folders**, then choose **Add directory…**. Each pinned folder gets its own Dock icon.

Left-click a folder icon to browse its files and subdirectories. Choose **Open Current Folder** to open the folder you're browsing in your file manager. To open the pinned folder directly, right-click its icon and choose **Open**.
